# 我的错题本 · 高中全科

一个能陪你三年的错题本。**单个 HTML 文件，打开即用，数据存在浏览器里不上传。**

👉 **[点这里打开错题本](https://xiaoman-zhang258.github.io/mistake-book/)**（手机、电脑都能用）

## 特点

- **覆盖高中九科**：语文、数学、英语、物理、化学、生物、政治、历史、地理
- **记的是思路，不是抄题**：每道错题都记录「错因（当时怎么想错的）」＋「正确思路」，这才是错题本的价值
- **自动统计**：总错题数、涉及科目、**最薄弱科目**（哪科错得最多一眼看到）
- **按科目筛选**：点顶部标签只看某一科
- **永久保存**：数据存在你这台设备的浏览器里，关掉页面不丢
- **导出 / 导入备份**：换设备时把数据搬走
- 深色 / 浅色模式自适应，手机竖屏适配

## 怎么用

1. 答错了题 → 点「＋ 添加错题」
2. 选科目，填题目、你的错答、正确答案、**错在哪一步**、**正确思路**
3. 每周把旧错题重做一遍，直到不再错

## 数据说明

所有错题保存在**当前设备的浏览器本地存储（localStorage）**里，不会上传到任何服务器。

注意：不同设备（比如电脑和手机）的数据各存各的，不会自动同步。想跨设备，用「导出备份」复制内容，到另一台设备用「导入备份」粘回去。

## 想改？

直接编辑 `index.html`，所有代码都在这一个文件里。种子错题在 JS 的 `SEED` 数组，科目列表在 `SUBJECTS` 数组。

## AI 自动收录

以后学习陪练时，如果出现概念型、思路型、记混型或方法型错题，AI 助手会自动把错题追加到 `index.html` 的 `SEED` 数组里。明显输入手滑、拼音笔误、用户明确表示本来知道的误输入不收录。

追加脚本：

```bash
node scripts/add-mistake.mjs < mistake.json
```

`mistake.json` 格式：

```json
{
  "subject": "生物",
  "date": "2026-07-30",
  "q": "题目",
  "mine": "我的错答",
  "right": "正确答案",
  "why": "错因：当时怎么想错的",
  "fix": "正确思路：方法、口诀或自查法"
}
```
